## 1\. Gemini 대화 안에서 문서 · 표 만들고 바로 고치기

**무엇이 바뀌었나.** Google이 10월 29일 발표한 기능입니다(출처 10, 11). Gemini 대화 안에서 문서, PDF, 발표자료, 스프레드시트 등을 만들고, 미리 보고, 고칠 수 있습니다. 결과물을 열어 직접 고쳐도 되고, 특정 부분만 골라 Gemini에게 수정을 맡겨도 됩니다. Google은 Gemini 앱을 쓸 수 있는 모든 언어의 모든 사용자에게 이 기능을 연다고 밝혔고, Gemini 웹 앱 공식 지원 언어에는 한국어가 들어 있습니다. PDF 미리보기 · 편집은 웹과 모바일에서, Google Docs · Sheets · 슬라이드 등 나머지 형식은 웹에서 됩니다.

**이렇게 써 봅니다.** 한빛기획 총무팀 김 대리는 월요일 회의 메모를 주간 업무 보고서로 정리하고, 회의에서 나온 비품 요청은 표로 따로 뽑아야 합니다. 메모를 붙여 넣어 보고서 문서를 만들게 한 뒤, 결과 문서를 열어 날짜와 제목은 직접 고치고 「이번 주 계획」 문단만 골라 담당자별로 다시 나눠 달라고 요청합니다.

요청문 틀 - 회의 메모로 보고서와 표 만들기

```
[회의 메모 붙여 넣기]

요청: 위 메모로 주간 업무 보고서 문서 작성
구성: 지난주 실적 / 이번 주 계획 / 결정 사항 / 담당자별 할 일
분량: A4 1쪽 안팎, 결론 먼저
조건: 메모에 없는 숫자 · 날짜 추가 금지, 빈 곳은 [확인 필요] 표시
추가: 비품 요청만 따로 표로 정리(품목 · 수량 · 요청자 · 필요한 날)

--- 결과 문서에서 문단을 골라 이어서 요청 ---
고른 문단: 담당자별로 다시 나누고 담당자 이름 순으로 정렬
```

> [!note] Note
> 확인
> 
> Gemini 웹에서 위 틀을 넣었을 때 대화 안에서 문서가 열리고 바로 고칠 수 있으면 내 계정에 들어온 것입니다. 회사 Google Workspace 계정은 관리자 설정에 따른 제한이 발표문에 나와 있지 않으므로, 개인 계정과 결과가 다르면 사내 관리자에게 확인합니다.

> [!note] Note
> 주의
> 
> 지원 언어 목록에 한국어가 있어도, 한국 계정에서 파일 형식마다 모두 켜졌는지는 공식 문서로 확인되지 않았습니다. 만든 문서의 숫자 · 날짜 · 담당자는 원래 메모와 한 번 대조합니다.

## 2\. ChatGPT에 회의 녹음 파일 올려 정리하기

**무엇이 바뀌었나.** OpenAI가 10월 6일 릴리스 노트에 올린 기능입니다(출처 1). ChatGPT 대화에 오디오 파일을 첨부해 녹취록을 만들고, 내용을 요약하고, 질문할 수 있습니다. 대상은 유료 ChatGPT 구독과 작업공간이며, 작업공간 설정 · 지역 · 앱 버전 · 모델에 따라 쓸 수 있는지가 달라질 수 있다고 안내합니다.

**이렇게 써 봅니다.** 한빛기획 영업기획팀은 주간 회의를 녹음해 두지만 회의록 정리가 늘 밀립니다. 회의가 끝나면 녹음 파일을 올려 결정 사항, 담당자별 할 일, 참석자에게 보낼 후속 메일 초안까지 한 번에 받습니다.

요청문 틀 - 회의 녹음 정리

```
[회의 녹음 파일 첨부]

요청: 첨부한 회의 녹음 정리
1. 녹취록
2. 결정 사항
3. 담당자별 할 일(담당자 · 할 일 · 기한)
4. 참석자에게 보낼 후속 메일 초안(5줄 안팎)
조건: 잘 들리지 않거나 확실하지 않은 부분은 [확인 필요] 표시,
      녹음에 없는 내용 추가 금지
```

> [!note] Note
> 확인
> 
> 유료 계정에서 짧은 오디오 파일 하나를 대화에 첨부해 봅니다. 첨부가 되지 않으면 앱을 최신 버전으로 바꾸거나 다른 모델을 골라 다시 해 보고, 회사 작업공간 계정이면 관리자 설정을 확인합니다.

> [!note] Note
> 주의
> 
> 녹취에는 오류가 섞일 수 있으므로 결정 사항 · 숫자 · 이름은 원음과 대조합니다. 한국 지역 제공과 한국어 오디오 지원 수준은 릴리스 노트에 명시되어 있지 않고, OpenAI는 언어마다 성능 차이가 있을 수 있다고 안내합니다. 녹음을 올리기 전에 참석자에게 알리고, 고객 통화처럼 외부인이 들어간 녹음은 회사 보안 규정부터 확인합니다.

## 3\. Word 안에서 ChatGPT로 초안 쓰고 다듬기

**무엇이 바뀌었나.** OpenAI가 9월 17일 릴리스 노트에 올린 기능입니다(출처 1). Microsoft Word 안의 ChatGPT 사이드바에서 메모를 보고 초안을 쓰고, 문서를 요약하고, 고른 문장과 제목 · 서식을 고칠 수 있습니다. Excel · PowerPoint에서 쓰던 것과 같은 Microsoft 추가 기능입니다. Free를 포함한 모든 ChatGPT 요금제가 대상이며, 사용량 제한은 요금제마다 다릅니다.

**이렇게 써 봅니다.** 한빛기획 교육사업팀 박 과장은 고객사 워크숍 제안서를 Word로 써야 합니다. 통화하며 적은 메모로 초안을 받은 뒤, 문서 안에서 바로 문단을 골라 공식 문체로 다듬습니다.

요청문 틀 - Word 사이드바에서 초안과 다듬기

```
[1단계 - 초안]
요청: 아래 메모로 워크숍 제안서 초안 작성
구성: 배경 / 목표 / 진행 방식 / 일정 / 준비 사항
문체: 합니다체, 문단마다 3~4문장
조건: 메모에 없는 일정 · 인원 · 금액 추가 금지, 빈 곳은 [확인 필요] 표시
[메모 붙여 넣기]

[2단계 - 고른 문단 다듬기]
요청: 고른 문단을 공식 문서 문체로 다듬기, 뜻과 숫자는 그대로
```

> [!note] Note
> 확인
> 
> Word에서 Microsoft Marketplace의 ChatGPT 추가 기능을 설치하고 ChatGPT 계정으로 로그인합니다. 사이드바가 열리고 위 요청이 문서에 반영되면 쓸 수 있는 상태입니다. 회사 PC라면 추가 기능 설치가 사내 규정에 맞는지 먼저 확인합니다.

> [!note] Note
> 주의
> 
> 고객사 이름 · 계약 조건 같은 회사 자료는 넣기 전에 사내 규정을 확인하고, 처음에는 가상 자료로 시험합니다.

## 4\. Claude 한 대화에서 질문부터 보고서 · 발표자료까지

**무엇이 바뀌었나.** Anthropic이 9월 16일 발표한 변경입니다(출처 5). 이제 Claude에서 일반 대화와 Cowork를 따로 고르지 않습니다. 대화 안에서 질문부터 보고서 · 스프레드시트 · 발표자료 같은 큰 작업까지 이어서 요청하고, 기존 대화 · 프로젝트 · 커넥터 · 스킬도 그대로 이어 씁니다. 발표 당시 Pro · Max 등 유료 요금제부터 웹 · 데스크톱 · 모바일에 단계적으로 배포했고, 공식 발표문에는 10월 23일 Enterprise 일반 제공 안내가 더해졌습니다.

**이렇게 써 봅니다.** 한빛기획 마케팅팀은 분기 고객 설문 결과를 팀장에게 보고해야 합니다. 먼저 설문 결과를 올려 눈에 띄는 경향을 묻고, 같은 대화에서 보고서를 쓰게 한 뒤, 이어서 발표자료까지 만듭니다. 앞에서 나눈 질문과 답을 같은 대화에서 이어 쓰므로 보고서와 발표자료의 내용을 맞추기 쉽습니다. 긴 요청서를 한 번에 넣기보다 아래처럼 세 번에 나눠 넣는 편이 고치기 쉽습니다.

요청문 틀 - 한 대화에서 세 단계로

```
[1단계] 첨부한 설문 결과에서 눈에 띄는 경향 3개와 근거 문항 정리
[2단계] 위 내용으로 팀장 보고용 주간 보고서 작성(A4 1쪽, 결론 먼저)
[3단계] 같은 내용으로 발표자료 5장 작성(장마다 제목 한 줄 + 핵심 3줄)
공통 조건: 설문에 없는 숫자 추가 금지, 사실과 해석을 나눠 표시
```

> [!note] Note
> 확인
> 
> 유료 계정에서 위 1~3단계를 한 대화에 차례로 넣어, 같은 대화에서 작업을 이어 갈 수 있는지 시험합니다. 이 결과만으로 Cowork 통합 여부를 확정하지 말고, 계정에 표시된 기능 안내도 확인합니다. Free · Team 요금제는 기준일 현재 배포가 끝났는지 공식 문서로 확인되지 않았습니다.

> [!note] Note
> 참고
> 
> 같은 날 Claude Docs · Slides · Design도 발표되었습니다. Claude 릴리스 노트는 Free를 포함한 모든 요금제(Enterprise는 베타)라고 적었고, 별도 발표문은 유료 요금제 베타로 설명해 두 공식 안내가 서로 다릅니다(출처 5, 6). Free 계정에서 쓸 수 있는지는 직접 열어 보고 판단합니다.

> [!note] Note
> 주의
> 
> 만든 보고서와 발표자료의 숫자는 설문 원자료와 대조합니다.

## 5\. Copilot in Excel로 반복 데이터 정리 맡기기

**무엇이 바뀌었나.** Microsoft가 10월 12일 Excel 블로그에 소개하고 10월 16일 수정한 내용입니다(출처 12). 데이터를 가져오고(Get data) 정리하는(Clean data) 기능, 반복 업무를 가르쳐 두는 Skill builder · Skill recorder, 데이터를 대화형 화면으로 바꾸는 Interactive canvas입니다. 기능마다 배포 단계가 다릅니다.

| 기능 | 발표문 기준 배포 단계 |
| --- | --- |
| Skill builder | 10월 중 일반 제공 배포 시작 |
| Clean data | 10월 중 일반 제공 배포 시작 |
| Get data | 10월 중순 웹에서 일반 제공 배포 예정(발표 당시) |
| Interactive canvas | Insider 대상 |
| Skill recorder | 10월 말까지 Insider에 제공 예정(발표 당시) |

**이렇게 써 봅니다.** 한빛기획 경영지원팀은 매달 지점에서 받은 매출 파일의 빈 행을 지우고, 날짜 형식과 지점 이름 표기를 맞춘 뒤 합계 표를 만듭니다. 이 순서를 한 번 글로 적어 두면 Skill builder에 설명할 때도, 다른 AI 도구에 맡길 때도 그대로 씁니다. 다음 달에도 설명을 다시 쓰되, 파일 구조와 처리 조건이 같은지 확인하고 결과를 원본과 대조합니다.

반복 작업 설명 틀 - 월별 파일 정리

```
작업 이름: 지점별 월 매출 파일 정리
입력: 지점에서 받은 월별 매출 시트
순서:
1. 빈 행 삭제, 중복 행은 표시만
2. 날짜를 YYYY-MM-DD 형식으로 통일
3. 지점 이름 표기 통일(예: 서울 1지점 / 서울1지점 → 서울1지점)
4. 지점별 합계 표 만들기
확인: 정리 전후 행 수와 지점별 합계 비교, 차이가 나면 해당 행 목록 표시
```

> [!note] Note
> 확인
> 
> Excel의 Copilot에서 위 기능을 쓸 수 있는지 먼저 확인합니다. Insider 대상 기능은 일반 사용자 화면에 없을 수 있고, 회사 Microsoft 365 계정의 라이선스는 IT 담당자에게 확인합니다.

> [!note] Note
> 주의
> 
> Copilot in Excel의 일반 지원 언어에는 한국어가 들어 있지만(출처 13), 이것만으로 새 기능 전체가 한국어를 지원한다고 볼 수는 없습니다. 「예정」으로 안내된 기능은 실제 출시 여부도 확인하고, 정리 전에는 원본 사본을 남깁니다.

## 나머지 8건 짧게 보기

나머지 항목은 표에 없는 이용 조건과 작업 경로만 덧붙입니다.

- **GPT-6 · Intelligent UI(출처 2)**: Enterprise는 관리자 설정의 영향을 받습니다. 이 발표는 Chat 탭 이야기이고 Work · Codex의 모델 변경은 들어 있지 않으므로, 팀에 알릴 때는 어느 탭 이야기인지 함께 적습니다.
- **ChatGPT Slides(출처 3)**: Space에서 팀과 함께 편집하고, 웹에서 PowerPoint · PDF · Google Slides로 내보냅니다. 웹과 데스크톱 앱에 단계적으로 배포합니다.
- **Codex Cloud · GPT-6.1 Sol(출처 1)**: 저장소 · 도구 · 의존성을 담은 재사용 환경에서 작업하고, 작업마다 독립된 환경에서 진행됩니다. 관리형 작업공간에는 모델과 클라우드 접근 설정이 적용됩니다.
- **GPT-6.1 Terra(출처 4)**: 일반 Chat 탭이 아니라 ChatGPT Work와 Codex에서 쓰며, 지역 · 요금제 · 작업공간 권한에 따라 이용이 달라집니다.
- **Claude Docs · Slides · Design(출처 5, 6)**: 릴리스 노트는 대화 외에 Claude Code와 Artifacts 탭도 작업 경로로 안내합니다.
- **Claude Sonnet 5.5 · Claude Haiku 5.5(출처 6, 7)**: Anthropic은 Sonnet 5.5를 Opus 5.5보다 빠르고 비용이 낮은 모델로, Haiku 5.5를 요약 · 분류 · 데이터베이스 질의 같은 대량 · 반복 작업용 소형 모델로 소개했습니다. Max · Team의 월간 API 크레딧은 Claude Console 조직을 연결해야 받습니다.
- **Claude Duet(출처 6, 8)**: Claude가 능동적인 에이전트로 일하는 별도 앱입니다.
- **Gemini 연결 앱(출처 9)**: Airtable · Linear · monday.com · PandaDoc · Zoho, Adobe · Squarespace · Webflow 등을 설정에서 연결하거나 대화에서 @로 불러옵니다.

```
□ 1. 출처: 회사 공식 발표 · 릴리스 노트 · 도움말 문서 여부
```


> [!note] Note
> 주의
> 
> **발표 글만 보고 팀 전체에 안내하기.** 직접 열어 본 결과로 안내합니다.

> 
> **공식 문서 하나만 보고 요금제를 단정하기.** Claude Docs · Slides · Design처럼 같은 회사 문서끼리 설명이 다를 수 있습니다.

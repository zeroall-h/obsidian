# 블로그 자동화 시스템

목표: 네이버 블로그 주 2편 발행 → 6개월~1년 안에 월 100만 원. ([[나의 핵심 맥락]])

## 흐름
```
/blog-trend  →  20_블로그소재/트렌드 리포트 + 소재 노트
     ↓ (주제 고르기, 직접 사서 써보기·가보기, 경험 메모)
/blog-draft  →  30_블로그/초안/
     ↓ ([직접 확인] 자리 채우기, 사진 준비)
/blog-publish → 점검 → OK → 클립보드 복사 → 네이버에 붙여 넣고 발행 → URL 기록 → 30_블로그/발행/
```

## 주간 루틴 (예시)
| 요일 | 할 일 |
|---|---|
| 월 | `/blog-trend`로 이번 주 2편 주제 고르기 |
| 화~목 | 사기·가보기, 사진 찍기, 경험 메모 |
| 목·금 | `/blog-draft` → 채우기 → `/blog-publish` |
| 일 | 발행 글 조회수 확인, 다음 주 반영 |

## 원칙
- AI는 조사·구성·문장을 맡고, **경험과 사진은 내가** 채운다. 네이버는 실제 경험 글을 우대하고, 지어낸 후기는 신뢰와 계정 모두에 위험하다.
- 발행은 내가 OK한 글만.

# /blog-draft — 네이버 블로그 초안 작성

## 절대 규칙
- **경험을 지어내지 않는다.** 맛·사용감·분위기·효과는 사용자가 준 경험(소재 노트의 `내 경험 메모` 또는 채팅)만 쓴다. 없으면 `[직접 확인: 무엇을 쓰면 되는지]` 자리로 남긴다.
- **사실은 출처로 확인한다.** 가격·용량·품번·위치·영업시간·성분은 WebSearch/WebFetch로 확인하고, 확인일을 소재 노트 `출처`에 남긴다. 확인 못 한 값은 `[직접 확인: 가격]`처럼 둔다.
- 협찬·제공·제휴 링크가 있으면 글 맨 위에 표기 자리를 둔다.

## 1. 읽기
- `나의 핵심 맥락.md`(타깃 독자), 소재 노트, `90_템플릿/블로그 초안.md`
- 경험 메모가 비어 있으면 먼저 짧게 묻는다: "직접 써보거나 가봤나요? 좋았던 점·아쉬운 점·사진 몇 장 있나요?" 답이 없으면 자리만 남기고 진행한다.

## 2. 키워드
- 핵심 키워드 1개(검색할 법한 그대로, 예: "다이소 수분크림 추천"), 서브 키워드 3~5개
- 제목: 핵심 키워드를 앞쪽에, 25~35자, 구체적 숫자·결론 포함 (예: "다이소 수분크림 3종 2주 써본 비교, 건성은 이거")
- 본문에 핵심 키워드를 자연스럽게 3~5회, 억지 반복 금지

## 3. 구성 (본문 1,500~2,500자)
1. **도입 2~3문장:** 검색한 사람의 고민 → 결론 먼저
2. **한눈에 보기 표:** 가격, 구매처/위치, 추천 대상 (맛집이면 주소·영업시간·주차·웨이팅)
3. **본문 소제목 3~5개:** 제품이면 구성/사용감/비교, 맛집이면 분위기/메뉴/맛/가격
4. **장점 / 아쉬운 점:** 둘 다 쓴다(신뢰도)
5. **총평 + 추천 대상:** 누구에게 사라고/가라고 할지
6. **태그 10개:** 핵심·서브 키워드 + 카테고리 + 지역

사진 자리는 `[사진 N: 찍을 장면]`으로 8~12개 넣는다(네이버는 사진 많은 경험 글이 유리). 문단은 2~3줄로 짧게, 모바일에서 읽기 편하게.

## 4. 저장
- `30_블로그/초안/YYYY-MM-DD <제목>.md` (템플릿 frontmatter 채움, `상태: 초안`, `소재 노트` 링크)
- 소재 노트 `상태`를 `초안작성`으로 바꾼다.

## 5. 보고
- 제목, 핵심 키워드, 글자 수
- 남은 `[직접 확인: …]` 목록(체크리스트)과 필요한 사진 목록
- "채워 주시거나 말로 알려주시면 반영하고, 다 되면 `/blog-publish`로 발행 준비를 해요."

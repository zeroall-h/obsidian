# /blog-publish — 발행 점검 → 붙여 넣기 → 기록

**사용자가 OK하지 않은 글은 발행 단계로 넘기지 않는다.**

## A. 발행 전 점검
초안을 읽고 아래를 표로 보여준다:
| 점검 | 기준 |
|---|---|
| 남은 자리 | `[직접 확인: …]`이 0개인가 (남아 있으면 목록) |
| 사진 | `[사진 N: …]` 개수와 장면 목록 — 사용자가 준비했는지 묻는다 |
| 사실 | 가격·영업시간 등 확인일이 2주 이내인가 |
| 키워드 | 제목 앞쪽에 핵심 키워드, 본문 3~5회, 태그 10개 |
| 표기 | 협찬·제휴면 표기 문구가 있나 |
| 과장 | 효능·건강 주장, "무조건", "최고" 같은 단정 표현 |

문제가 있으면 고칠 곳을 제안하고 멈춘다. 다 통과하면 "이대로 발행할까요?"라고 묻는다.

## B. 붙여 넣기용 변환 (OK를 받은 뒤)
네이버 에디터는 마크다운을 지원하지 않으므로:
- frontmatter, HTML 주석 제거
- `##` 소제목 → 앞뒤 빈 줄을 둔 일반 줄 (에디터에서 직접 소제목 서식 지정)
- 표 → `· 항목: 내용` 줄로
- `[사진 N: …]` → `📷 사진 N` 표시만 남김 (그 자리에 사진 넣기)
- `**굵게**` 기호 제거, 태그 줄은 `#태그` 형태로 맨 끝에

변환본을 스크래치 파일로 저장한 뒤 PowerShell로 클립보드에 복사한다:
```powershell
Get-Content -Raw -Encoding utf8 "<변환본 경로>" | Set-Clipboard
```
그리고 안내한다: "네이버 블로그 글쓰기 → 제목 입력 → 본문에 붙여 넣기 → 📷 자리에 사진 → 소제목 서식 → 발행. 발행 후 URL을 알려주세요."

## C. 발행 기록 (URL을 받으면)
- 초안 frontmatter: `상태: 발행`, `발행일`, `발행 URL` 채움
- 파일을 `30_블로그/발행/`으로 옮긴다
- 소재 노트 `상태`를 `발행`으로
- 이번 주 발행 수를 알려준다(목표 주 2편).

## 나중에 붙일 것
네이버 블로그는 공식 글쓰기 API가 없어 자동 발행은 브라우저 자동화(Claude in Chrome)로만 가능하다. 계정 제재 위험이 있어 지금은 붙여 넣기 방식으로 운영하고, 원하면 `40_자동화/블로그 자동화 시스템.md`의 다음 단계로 검토한다.
